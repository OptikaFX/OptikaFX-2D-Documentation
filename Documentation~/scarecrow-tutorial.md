# Scarecrow Tutorial

The Scarecrow Tutorial is a guided sample scene for learning the basic OptikaFX 2D setup.

Scene name:

    01 - Scarecrow Tutorial

When this scene is opened, the `Scarecrow Tutorial` window appears automatically.

---

## What You Will Learn

This tutorial shows how to:

- Run the OptikaFX Full Setup
- Add a Ground Receiver
- Add Perspective Casters
- Add a Wall Receiver
- Enable TimeManager
- Test the day-night cycle

---

## How to Start

1. Open the scene:
   
```text
01 - Scarecrow Tutorial
```

Wait for the Scarecrow Tutorial window to appear.

Click:
   
```text
Start Tutorial
```


2. Follow each task in the window.

---

## If the Tutorial Window Does Not Open

Check that:

- You opened the correct scene: `01 - Scarecrow Tutorial`
- Unity finished compiling scripts
- The tutorial Editor script is included in the project

You can also reopen the scene to trigger the window again.
