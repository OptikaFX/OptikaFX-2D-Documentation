# Changelog

## 1.0.0

### Added

- Dynamic 2D shadow framework for URP.
- Projected, Rotation, Mixed, Occlusion and Blob shadow modes.
- Sprite and Tilemap receivers.
- Global Light and Local Light support.
- Light Resolver support.
- TimeManager and DayLightingPreset support.
- Occluder support.
- Wall bending support.
- ShadowRenderQuad camera rendering.
- Optional Clock UI with TextMeshPro.
- Automatic URP Render Feature setup.
- Editor setup menus.
